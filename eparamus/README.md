# eParamus mockup

Static HTML mockups for the eParamus marketing site. Each page shares the same nav, styling, and browser chrome. Open any file directly in a browser — all nav links are cross-linked.

## Pages

**Homepage**
- `nav_mockup_standalone.html` — hero with tagline

**Platform**
- `platform-overview.html` — overview with feature cards linking to sub-pages
- `platform-mid-generator.html` — 4-step workflow for generating MIDs
- `platform-workforce-capability-insight.html` — feature cards (gap analysis, impact tracking, dashboards, trends)

**How it works**
- `how-it-works.html` — connected timeline with Define → Build → Verify → Act steps

**Solutions** (each with a persona-specific value proposition)
- `solutions-learning-leaders.html`
- `solutions-instructional-design-teams.html`
- `solutions-business-leaders.html`

**Resources**
- `resources-articles.html` — article listing with tags and dates
- `resources-case-studies.html` — customer stories with outcome stats
- `resources-videos.html` — video grid with placeholder thumbnails and durations
- `resources-guides.html` — downloadable guides with page counts

**About**
- `about.html` — mission, values, and placeholder team section
